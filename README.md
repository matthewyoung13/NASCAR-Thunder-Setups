# NASCAR Thunder Setups

A static website that archives garage setups for EA Sports' NASCAR Thunder 2003, 2004 and 2005, collected from old fan sites.

The site is generated by a small Kotlin program from YAML files in `data/`. There is no server or database, and the output in `build/site` can be hosted anywhere (GitHub Pages by default).

## Commands

```bash
./gradlew generate      # build the site into build/site (fails if the data has mistakes)
./gradlew test          # importer and data-validation tests
jwebserver -d "$PWD/build/site"   # preview at http://localhost:8000 (comes with JDK 18+)
```

## Adding or editing setups

Edit the YAML under `data/setups/<game>/<series>.yaml`. Each entry looks like this:

```yaml
- track: bristol            # an id from data/tracks.yaml
  author: Warhawk
  tirePressure: 20          # psi
  fenderFlare: 76.0         # inches, leave out if N/A
  rearSpoiler: 70           # degrees
  frontSprings: 100         # %
  rearSprings: 100          # %
  swayBar: 3/4 in           # Thunder 2003 only
  wedge: 0.5                # turns
  gears:
    preset: 3               # and/or ratios: [3.60, 2.30, 1.80, 1.38]; null = default
    rearEnd: 3.30
  bestLap: "14.985"
  notes: Anything a reader should know
  source: Where it was found
```

`./gradlew generate` checks the data first and lists any problems: unknown tracks, settings a game doesn't have, out-of-range values, or duplicates.

- New track: add it to `data/tracks.yaml`.
- New game: add it to `data/games.yaml` with the garage settings it has, then add `data/setups/<game-id>/cup.yaml`.

## Importing more text dumps

`raw/` holds the original text files. To convert a new one, save it as `raw/<game-id>.txt` and run:

```bash
./gradlew importTxt
```

This writes draft YAML to `build/import/setups/` and a list of anything it wasn't sure about to `build/import/REVIEW.md`. Check those items, then copy the YAML into `data/setups/`. Running it again overwrites only `build/import`, never `data/`.

## Layout

```
data/                     games, series, tracks and setups (the source of truth)
raw/                      original text the setups were imported from
site-static/              CSS, JS and favicon, copied as-is
src/main/kotlin/setups/
  model/                  data classes
  load/                   YAML loading and validation
  render/                 HTML pages (kotlinx.html)
  importer/               text → YAML converter
.github/workflows/        GitHub Pages deploy
```
